# Ink Aural v1.0.0

**スマホ完結型配信プラットフォーム向けコメント読み上げシステム**
by [Ink Inc.](https://inkinc-hp.vercel.app/) / 黒井葉跡

---

## これは何？

スマホ完結型の配信プラットフォームでは、OBSなどのPC連携ツールが使えません。
Ink Auralは **USBカメラでスマホ画面を撮影し、OCRでコメントを読み取り、PCから音声で読み上げる** という方法でこの制限を突破します。

ミキサーやオーディオインターフェース経由でスマホ配信に音声を乗せているライバー向けのツールです。

**このツールのコンセプトは「完璧な読み上げ」ではありません。**
配信者がコメント欄から目を離し、ライバーとの会話に集中するための補助ツールです。
読み間違い・読み飛ばしは仕様の範囲内です。

---

## プライバシーについて

- 配信プラットフォームのサーバーには一切アクセスしません
- コメントデータをサーバーに送信しません
- AIの学習には使用しません
- すべての処理はローカルPC内で完結します
- AIは内蔵されていません

※本ツールはAIを使って開発しましたが、動作中にAIは使用していません。

## セットアップ（重要）

### Windows

インストーラー実行前に **Python 3.9以上** を別途インストールしてください。

1. [python.org](https://www.python.org/downloads/windows/) から Windows installer (64-bit) をダウンロード
2. インストール時に **「Add Python to PATH」に必ずチェックを入れる**
3. `Ink Aural Setup 1.0.0.exe` を実行してインストール
4. 初回起動時のセットアップ画面で「セットアップ開始」を押す

> **⚠️ 「Add Python to PATH」を忘れると音声が鳴りません。**
> その場合はPythonを再インストールしてチェックを入れ直してください。

音声はWindowsの標準TTS（SAPI5）を使用します。システムにインストールされている音声によって声質が異なります。

### Linux（Ubuntu）

セットアップ画面が自動的に Open JTalk をインストールします（sudo権限が必要）。

AppImage起動時は必ず `--no-sandbox` オプションをつけてください。

## 使い方

1. USBカメラをPCに接続してスマホのコメント欄に向ける
2. アプリを起動してカメラを選択
3. 金色のガイド枠をコメント欄に合わせる
4. **USBカメラのピントとスマホ画面の輝度を調整する**（後述）
5. **▶ 開始** を押す
6. コメントが読み上げられる

> 初回起動時はEasyOCRのモデル読み込みに数十秒かかります。「EasyOCR準備完了」が表示されるまでお待ちください。

### カメラ・画面の調整について

OCRの認識精度はUSBカメラのピントとスマホ画面の輝度に大きく左右されます。カメラの個体差・スマホの個体差・部屋の照明環境によって最適な設定は異なります。**Ink Auralが読み取りやすいようにUSBカメラのピントとスマホ画面の輝度を調整してお使いください。**

### 読み上げ音声のボリューム調整

Ink Auralには音量調整機能がありません。PCのシステム設定から調整してください。

**Windows：**
タスクバーの音量アイコンを右クリック →「サウンドミキサーを開く」→ Ink Aural または Python の音量を調整

**Linux（Ubuntu）：**
```bash
pavucontrol
```
を起動して「再生」タブからPythonの音量を調整

### MEMOと話題ストックについて

**MEMO欄**は上書き保存のため、配信中の「今この瞬間の状況」を書く場所として使うのがコツです。話がブレそうになったとき、見返すための一枚メモとして活用してください。配信後の記録として残したい場合は、下の「Ink Memory Lite」にコピーするとデータベース化できます。

**話題ストック欄**は次回以降の配信で使いたい話題をストック保存できます。MEMO欄と使い分けることで、今の配信と将来の配信を切り分けて管理できます。

### 音声フロー

```
PC（Ink Aural読み上げ音声）
　↓
ミキサー / オーディオインターフェース
　├── PC音声（BGM + 読み上げ）
　└── マイク音声（ライバーの声）
　↓
配信用スマホ → 配信
```

## 制限事項

OCRはカメラ映像から文字を読み取る方式のため、以下の制限があります。

| コメント速度 | 動作 |
|------------|------|
| ゆっくり（5秒に1件以下） | 読み上げ可能 |
| 普通（2〜5秒に1件） | 一部読み飛ばしあり |
| 速い（1〜2秒に1件） | 読み飛ばし・順番の乱れが発生 |
| 超高速（1秒に複数件） | 追いつけない |

- 絵文字が文字として誤認識される場合があります
- ライバー名など特殊な読みは読み間違いが発生します
- 画面の明るさ・カメラの角度によって精度が変わります
- 音声はOS標準のTTSのため機械的な読み上げになります

## トラブルシューティング

**音声が鳴らない（Windows）**
→ Pythonインストール時に「Add Python to PATH」にチェックが入っているか確認してください。入っていない場合はPythonを再インストールしてください。

**「EasyOCRが見つかりません」と表示される**
→ セットアップ画面で「セットアップ開始」を再実行してください。

**カメラが表示されない**
→ USBカメラの接続を確認し、カメラ一覧の更新ボタンを押してください。それでも表示されない場合は、USBカメラを挿したままアプリを再起動してください。

**AppImageが起動しない（Linux）**
→ `--no-sandbox` オプションをつけて起動してください。

**文字化けする**
→ ファイルを差し替える際は必ずダウンロードしたファイルを直接上書きしてください。
